# Portfolio

Static portfolio prototype with an editorial layout and reusable typography tokens.

## Files

- `index.html`: website entry point.
- `style.css`: layout, responsive styles, and typography tokens.
- `app.js`: placeholder projects, slideshow, index, and gallery interactions.
- `.nojekyll`: serve the files directly on GitHub Pages.

## Publishing

GitHub Pages publishing source: **Deploy from a branch**, branch **main**, folder **/(root)**.
Updates committed to `main` publish automatically.

The current site contains placeholder portfolio content. Unused local media and resume files are excluded from this deployment.
